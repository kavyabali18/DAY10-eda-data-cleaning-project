# Student Performance Analysis: Data Cleaning and Exploratory Data Analysis

## Overview
This project focuses on cleaning and analyzing student performance data using Python, Pandas, Matplotlib, and Seaborn.

## Objectives
- Inspect and understand the dataset structure.
- Handle missing values, duplicate records, and datatype issues.
- Perform exploratory data analysis (EDA).
- Visualize distributions, outliers, and feature relationships.
- Generate insights useful for machine learning applications.

## Dataset Features
- Student_ID
- Gender
- Age
- Study_Hours
- Attendance_Percentage
- Assignment_Score
- Midterm_Score
- Final_Exam_Score
- Extracurricular
- Performance_Score
- Grade

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Output Files
- `cleaned_dataset.csv`
- `eda_report.ipynb`

## Conclusion
The dataset was successfully cleaned and analyzed. Key insights were obtained regarding student performance, study habits, and exam scores, making the dataset suitable for further machine learning tasks.
